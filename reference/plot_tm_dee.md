# Make a histogram of D values

Make a histogram of D values

## Usage

``` r
plot_tm_dee(df, median_dee = NULL, xstr = "D", ystr = "Frequency")
```

## Arguments

- df:

  data frame of D values

- median_dee:

  variable for adding label to plot

- xstr:

  string to label x-axis

- ystr:

  string to label y-axis

## Value

ggplot
