# Find distance between xy coordinate and a series of other xy coordinates

Find distance between xy coordinate and a series of other xy coordinates

## Usage

``` r
find_distances(xx, yy, df)
```

## Arguments

- xx:

  x coord of point for comparison

- yy:

  y coord of point for comparison

- df:

  data frame containing x and y columns for other points

## Value

numeric vector of distances
