# Make a histogram of alpha values

Make a histogram of alpha values

## Usage

``` r
plot_tm_alpha(
  df,
  median_alpha = NULL,
  xstr = "alpha (log2)",
  ystr = "Frequency"
)
```

## Arguments

- df:

  data frame of alpha values

- median_alpha:

  variable for adding label to plot

- xstr:

  string to label x-axis

- ystr:

  string to label y-axis

## Value

ggplot
