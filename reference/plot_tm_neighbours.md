# Make a histogram of track density (number of neighbours)

Make a histogram of track density (number of neighbours)

## Usage

``` r
plot_tm_neighbours(df, auto = FALSE)
```

## Arguments

- df:

  data frame of TrackMate data

- auto:

  boolean to switch between returning a ggplot and a list of ggplot and
  variable

## Value

ggplot or list of ggplot and variable
